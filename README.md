# SNS ONE 月間投稿計画モック

スマホで顧客別の月間計画から記事制作・品質承認・お客様への提出までを確認する静的モック。

## 操作
顧客 → 詳細 → 月間計画を作る → 今月の依頼・要望 → 計画案を作成 → 計画を選択して採用 → 制作を開始 → 記事を確認・承認 → お客様へ提出。

「確認」から計画のタイトル・狙い・画像指示を修正できます。入力はブラウザのlocalStorageにのみ保存します。月別に保存されます。実際の個人情報・秘密情報は入力しないでください。

## 範囲
- 架空の「サンプル工房」を使用。
- 提案と本文は固定サンプル。外部API、AI生成、通知、配信、課金は行いません。
- ログイン・本番システムへの接続はありません。
- 画像は配置確認用の図です。
- データは端末間で共有されません。
